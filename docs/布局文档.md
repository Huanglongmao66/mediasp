# 跨平台视频播放器 - 布局文档

## 📐 设计原则

### 设计理念

本项目遵循 Material Design 3 设计规范，结合跨平台特性，提供统一且优质的用户体验。

#### 核心设计原则

1. **一致性**: 各平台保持视觉和交互一致性
2. **简洁性**: 界面简洁明了，功能直达
3. **响应式**: 自适应不同屏幕尺寸和方向
4. **可访问性**: 支持无障碍访问
5. **美感**: 现代化设计，视觉舒适

#### 响应式布局规则

```
手机竖屏 (宽度 < 600dp)
├── 列数: 2列
├── 卡片宽度: (屏幕宽度 - 48dp) / 2
└── 卡片高度: 卡片宽度 * 1.2

手机横屏 / 平板竖屏 (600dp ≤ 宽度 < 840dp)
├── 列数: 3列
├── 卡片宽度: (屏幕宽度 - 64dp) / 3
└── 卡片高度: 卡片宽度 * 1.2

平板横屏 / 桌面 (宽度 ≥ 840dp)
├── 列数: 4-6列 (自适应)
├── 卡片宽度: 180dp固定
└── 卡片高度: 216dp
```

```kotlin
TabRow(

    backgroundColor = MaterialTheme.colorScheme.surface,

```

**视频卡片**:
```kotlin
Card(
    modifier = Modifier
        .width(cardWidth)
        .height(cardHeight),
    shape = RoundedCornerShape(12.dp),
    elevation = CardDefaults.elevatedCardElevation(4.dp)
) {
    Column {
        // 封面图片 (占70%)
        AsyncImage(
            model = video.coverUrl,
            modifier = Modifier
                .fillMaxWidth()
                .weight(0.7f),
            contentScale = ContentScale.Crop
        )
        
        // 标题和时长 (占30%)
        Column(
            modifier = Modifier
                .fillMaxWidth()
                .weight(0.3f)
                .padding(8.dp)
        ) {
            Text(
                text = video.title,
                maxLines = 1,
                style = MaterialTheme.typography.titleSmall
            )
            Text(
                text = video.duration,
                style = MaterialTheme.typography.bodySmall,
                color = MaterialTheme.colorScheme.onSurfaceVariant
            )
        }
    }
}
```

| Mobile | 0-599dp | 手机竖屏 | 单列/双列网格 |
| Tablet | 600-839dp | 手机横屏/平板竖屏 | 3-4列网格 |
| Desktop | 840dp+ | 平板横屏/桌面 | 4-6列网格 |

### 自适应规则

#### 网格列数

```kotlin
@Composable
fun getGridColumns(width: Dp): Int {
    return when {
        width < 360.dp -> 2
        width < 600.dp -> 2
        width < 840.dp -> 3
        width < 1200.dp -> 4
        else -> 6
    }
}
```

#### 边距调整

```kotlin
@Composable
fun getScreenPadding(width: Dp): PaddingValues {
    return when {
        width < 600.dp -> PaddingValues(16.dp)
        width < 840.dp -> PaddingValues(24.dp)
        else -> PaddingValues(32.dp)
    }
}
```

#### 字体缩放

```kotlin
@Composable
fun getScaledTextStyle(baseStyle: TextStyle, width: Dp): TextStyle {
    val scale = when {
        width < 600.dp -> 1.0f
        width < 840.dp -> 1.1f
        else -> 1.2f
    }
    return baseStyle.copy(fontSize = baseStyle.fontSize * scale)
}
```
