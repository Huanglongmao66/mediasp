## 📚 学习笔记

### Kotlin Multiplatform 学习

#### 概念理解
- Kotlin Multiplatform (KMP) 允许使用Kotlin编写跨平台代码
- `commonMain` 包含共享代码
- `androidMain`、`desktopMain` 等包含平台特定代码
- `expect` 和 `actual` 用于声明和实现平台特定功能

#### 最佳实践
1. 业务逻辑尽量放在commonMain
2. 平台特定功能使用expect/actual机制
3. 使用跨平台库减少平台适配工作量

### Compose Multiplatform 学习

#### 核心概念
- 声明式UI框架
- 状态驱动UI更新
- 组合优于继承

#### 常用组件
- `Column`、`Row`、`Box` - 布局组件
- `Text`、`Image`、`Icon` - 基础组件
- `LazyColumn`、`LazyVerticalGrid` - 列表组件
- `Modifier` - UI修饰符
