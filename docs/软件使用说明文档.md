# 跨平台视频播放器 - 软件使用说明文档

## 📱 产品简介

### 产品名称
MultiPlatform Video Player (MPVP) - 跨平台视频播放器

### 产品定位
一款现代化的跨平台视频播放器，支持Windows、Android、iOS、macOS、Web多平台，提供本地视频播放和网络视频流播放功能。

### 核心功能
- 🎬 **视频播放**: 支持本地视频和网络视频流播放
- 📡 **流媒体支持**: m3u8、mp4、直播源
- ⏯️ **播放控制**: 播放/暂停、进度调节、倍速控制、音量调节
- 💾 **播放记录**: 自动保存播放进度，下次打开继续播放
- ❤️ **收藏管理**: 收藏喜欢的视频，快速访问
- 📂 **本地扫描**: 自动扫描设备中的视频文件
- 🌙 **暗黑模式**: 支持亮色/暗色主题切换
- 📱 **跨平台**: 一个应用，多端使用

## 🚀 快速开始

### 安装指南

#### Android安装
1. 下载APK安装包
2. 点击安装
3. 首次使用需要授予存储权限和网络权限

#### Windows安装
1. 下载.exe安装包
2. 双击运行安装程序
3. 选择安装路径
4. 完成安装后启动应用

#### macOS安装
1. 下载.dmg安装包
2. 打开dmg文件
3. 拖拽应用到应用程序文件夹
4. 启动应用

#### Web版本使用
1. 打开浏览器
2. 访问应用网址
3. 即可使用，无需安装

### 2. 视频播放页面

#### 功能说明
全屏视频播放界面，提供完整的播放控制功能。

#### 页面布局
```
┌─────────────────────────────────┐
│  ← 视频标题            ⋮ 更多   │  ← 顶部控制栏（自动隐藏）
├─────────────────────────────────┤
│                                 │
│                                 │
│          🎬 视频画面            │  ← 视频渲染区域
│                                 │
│                                 │
│         ⏯️ 播放/暂停            │  ← 中央控制按钮
│                                 │
├─────────────────────────────────┤
│  ⟲ 缓冲中...  或  ⚠️ 播放失败   │  ← 状态提示
├─────────────────────────────────┤
│  ▶️ ━━━━━━━━━━●━━━━━━  ⏸️ 10:30│  ← 进度条

│  ⟪ ⟪ ▶️ ⟫ ⟫  🔀  ⚙️  ⛶        │  ← 底部控制栏
│ 上一集 播放 下一集 倍速 设置 全屏│
└─────────────────────────────────┘
```

#### 播放控制

**基础控制**:
- **播放/暂停**: 点击中央按钮或屏幕
- **进度调节**: 拖动进度条
- **快进/快退**: 双击屏幕左右两侧

**高级控制**:
- **倍速播放**: 点击倍速按钮，选择0.5x ~ 3.0x
- **音量调节**: 上下滑动屏幕右侧
- **亮度调节**: 上下滑动屏幕左侧
- **全屏切换**: 点击全屏按钮或双击屏幕

**手势控制**:
```
左侧上下滑动 → 调整亮度
右侧上下滑动 → 调整音量
左右滑动 → 快进/快退
双击左侧 → 快退10秒
双击右侧 → 快进10秒
长按 → 3倍速快进
```

### 3. 本地视频扫描

#### 功能说明
自动扫描设备中的视频文件，并展示在列表中。

#### 使用步骤
1. 进入"本地"标签页
2. 首次使用点击"扫描视频"按钮
3. 等待扫描完成
4. 扫描到的视频将显示在列表中

#### 支持的视频格式
- MP4、MKV、AVI、MOV、WMV
- FLV、WebM、M4V、3GP

#### 注意事项
- Android需要授予存储权限
- iOS只能访问相册中的视频
- Desktop可以访问任意文件夹

### 4. 收藏管理

#### 功能说明
收藏喜欢的视频，方便快速访问。

#### 添加收藏
**方法一**:
1. 在视频列表页长按视频卡片
2. 选择"添加收藏"

**方法二**:
1. 进入播放页面
2. 点击右上角"⋮"更多按钮
3. 选择"添加收藏"

#### 查看收藏
1. 进入首页
2. 点击"收藏"标签
3. 查看所有收藏的视频

#### 取消收藏
1. 长按收藏视频卡片
2. 选择"取消收藏"

---

### 5. 播放历史

#### 功能说明
自动记录播放过的视频和播放进度。

#### 特性
- 自动记录播放进度
- 下次打开自动跳转到上次播放位置
- 显示最近播放时间和播放进度

#### 管理历史
- 查看历史：进入首页 → 点击"历史"标签
- 删除单条：长按视频卡片 → 选择"删除"
- 清空历史：点击右上角"清空历史"按钮

---

### 6. 在线视频

#### 功能说明
播放在线视频流，支持m3u8、mp4等格式。

#### 使用方法
1. 进入首页
2. 点击"在线"标签
3. 点击右上角"+"按钮
4. 输入视频地址或m3u8源地址
5. 点击"播放"

#### 支持的格式
- **视频格式**: MP4、MKV、AVI等
- **流媒体**: m3u8（HLS）、DASH
- **直播源**: RTMP、HTTP-FLV

#### CMS源支持（扩展功能）
- 支持导入CMS视频源
- 自动解析视频列表
- 支持搜索功能

**播放设置**:

## ❓ 常见问题解答（FAQ）

### Q1: 视频无法播放怎么办？
**A**: 
1. 检查视频格式是否支持
2. 检查网络连接是否正常
3. 尝试切换解码方式（设置 → 播放设置 → 解码方式）
4. 清除缓存后重试

### Q2: Android扫描不到本地视频？
**A**: 
1. 检查是否授予了存储权限
2. Android 13+需要授予媒体权限
3. 手动添加视频文件夹

### Q3: 播放卡顿怎么办？
**A**: 
1. 检查网络速度
2. 降低视频画质
3. 切换到硬解码
4. 清除播放缓存

### Q4: 如何记住播放进度？
**A**: 
播放进度会自动保存，确保设置中"记住播放位置"选项已开启。

### Q5: m3u8视频加载失败？
**A**: 
1. 检查链接是否有效
2. 检查网络是否可以访问该链接
3. 部分链接可能需要特定请求头

### Q6: 后台播放如何开启？
**A**: 
进入设置 → 播放设置 → 开启"后台播放"

### Q7: 如何导入CMS源？
**A**: 
1. 进入在线视频页面
2. 点击右上角"导入源"
3. 输入CMS源地址
4. 等待解析完成

## 🔒 隐私与安全

### 数据收集说明
- 本应用不收集任何用户数据
- 所有数据仅存储在用户本地设备
- 不会上传任何信息到服务器

### 权限使用说明
| 权限 | 用途 |
|------|------|
| 存储权限 | 读取本地视频文件 |
| 网络权限 | 播放在线视频 |
| 相册权限（iOS） | 访问相册中的视频 |

### 数据存储位置
- **Android**: `/data/data/包名/files/`
- **Desktop**: 用户目录下的应用文件夹
- **iOS**: 应用沙盒目录
- **Web**: 浏览器本地存储
