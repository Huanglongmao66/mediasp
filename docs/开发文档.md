# 跨平台视频播放器 - 开发文档

## 📌 项目概述

### 项目名称
MultiPlatform Video Player (MPVP)

### 项目简介
基于 Kotlin + Compose Multiplatform 开发的跨平台视频播放器应用，支持 Windows、Android、iOS、macOS、Web 五大平台。提供本地视频播放和网络视频流播放功能，具备完善的播放控制、进度管理、收藏历史等特性。

### 核心特性
- ✅ 跨平台支持：Windows / Android / iOS / macOS / Web
- ✅ 双模式播放：本地视频 + 在线网络视频
- ✅ 流媒体支持：m3u8 / mp4 / 直播源
- ✅ 播放控制：播放/暂停/进度/倍速/音量
- ✅ 数据持久化：播放进度缓存、收藏、历史记录
- ✅ 现代化UI：Material Design 3、自适应布局、暗黑模式
- ✅ 扩展性强：模块化设计，易于添加音乐/图片/小说/漫画模块

### MVVM + Clean Architecture

项目采用 MVVM + Clean Architecture 架构模式：

#### 1. Presentation Layer（表现层）
- **Compose UI**: 声明式UI，完全跨平台
- **ViewModel**: 管理UI状态，处理用户交互
- **StateFlow/Flow**: 响应式状态管理

#### 2. Domain Layer（领域层）
- **Use Cases**: 业务逻辑用例
- **Repository Interface**: 数据仓库接口
- **Domain Model**: 领域模型

#### 3. Data Layer（数据层）
- **Repository Implementation**: 仓库实现
- **DataStore**: 轻量级数据存储
- **Network**: 网络请求封装
- **FileSystem**: 本地文件访问

#### 4. Platform Layer（平台层）
- **Platform Specific**: 平台特定实现
- **Permissions**: 权限管理
- **MediaPlayer**: 媒体播放器适配

```kotlin
// ✅ 推荐：使用remember和derivedStateOf优化性能
@Composable
fun VideoListScreen(viewModel: VideoListViewModel) {
    val videos by viewModel.videos.collectAsState()
    
    // 派生状态，避免不必要的重组
    val isEmpty by remember {
        derivedStateOf { videos.isEmpty() }
    }
    
    if (isEmpty) {
        EmptyState()
    } else {
        VideoGrid(videos)
    }
}

// ✅ 推荐：使用LaunchedEffect处理副作用
LaunchedEffect(videoId) {
    viewModel.loadVideoDetail(videoId)
}

// ✅ 推荐：使用DisposableEffect管理生命周期
DisposableEffect(player) {
    player.initialize()
    onDispose {
        player.release()
    }
}

    <uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />
    
    <!-- Android 13+ 媒体权限 -->
    <uses-permission android:name="android.permission.READ_MEDIA_VIDEO" />
    <uses-permission android:name="android.permission.READ_MEDIA_IMAGES" />
    
    <!-- 后台播放 -->
    <uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
    <uses-permission android:name="android.permission.WAKE_LOCK" />
    
</manifest>

// 权限请求封装
@Composable
fun rememberPermissionState(
    permission: String,
    onResult: (Boolean) -> Unit
): PermissionState {
    val context = LocalContext.current
    
    val launcher = rememberLauncherForActivityResult(
        contract = ActivityResultContracts.RequestPermission()
    ) { granted ->
        onResult(granted)
    }
    
    return remember {
        object : PermissionState {
            override val permission = permission
            
            override fun request() {
                if (ContextCompat.checkSelfPermission(
                        context,
                        permission
                    ) == PackageManager.PERMISSION_GRANTED
                ) {
                    onResult(true)
                } else {
                    launcher.launch(permission)
                }
            }
        }
    }
}
```

class DesktopFilePicker {
    fun pickVideoFile(): String? {
        val fileDialog = FileDialog(Frame(), "选择视频文件", FileDialog.LOAD)
        fileDialog.file = "*.mp4;*.mkv;*.avi;*.m3u8"
        fileDialog.isVisible = true
        
        return if (fileDialog.file != null) {
            "${fileDialog.directory}${fileDialog.file}"
        } else {
            null
        }
    }
    
    fun pickVideoDirectory(): String? {
        val directoryDialog = JFileChooser()
        directoryDialog.fileSelectionMode = JFileChooser.DIRECTORIES_ONLY
        
        val result = directoryDialog.showOpenDialog(null)
        return if (result == JFileChooser.APPROVE_OPTION) {
            directoryDialog.selectedFile.absolutePath
        } else {
            null
        }
    }
}
